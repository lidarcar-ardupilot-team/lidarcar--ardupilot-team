# 灰度循迹、速度与安全控制

## 工作模式

| 模式 | 用途 | 禁止事项 |
| --- | --- | --- |
| `BENCH_FOUR_WHEEL` | 抬轮验证四轮 TB6612、方向和编码器 | 不初始化或依赖灰度循迹接口 |
| `COMPETITION_LINE_FOLLOW` | 赛道灰度循迹与任务协同 | 不用无线 ACK 或地面站指令接管电机状态机 |

## 已记录的竞赛接口

- 前 TB6612：`PA2/PA3` 为 20 kHz PWM，`PE2`–`PE5` 为方向，`PE6` 为安全默认低的 `STBY`。
- 前编码器：`TIM5 PA0/PA1` 与 `TIM3 PA6/PA7`。
- 灰度模块：`PC0/PC1/PC2` 驱动 74HC4051 风格地址 `AD0/AD1/AD2`，`PG0` 读取当前选中通道；它不是八个直接 GPIO 或 ADC 输入。
- 姿态输入：重映射 USART2 `PD5/PD6` 用于 JY901；不能占用前电机 PWM 的 `PA2/PA3`。

以上为当前电赛基线的接口事实。后桥 TB6612 和后编码器仍应按台架验证状态管理，不能据此宣称已完成四轮闭环竞赛验证。

## 运行规则

1. 仅物理按键可创建任务起点；任务运行中再次按任务键是安全停机。
2. 有效启动后，小车在本地完成延迟与循迹启动；没有 Pi 位姿也不应阻断本地灰度循迹。
3. 速度内环依赖编码器；JY901 仅施加有界航向修正；灰度误差始终是路径跟踪参考。
4. 丢线、传感器异常、方向不一致或安全门限触发时，输出必须回到安全状态并保留证据。
5. 先验证灰度物理顺序、黑白极性、左右误差符号和丢线策略，再提高速度或修改控制器。

## 验收等级

| 等级 | 最小证据 |
| --- | --- |
| `planned` | 接线/参数设计，尚无测量 |
| `bench-verified` | 抬轮方向、PWM、编码器或单传感器观测 |
| `field-verified` | 指定赛道、固件、PCB 版本和原始记录下的实际循迹 |

`PWM` 寄存器变化仅说明 MCU 输出发生变化，不证明电机扭矩、轮向或闭环质量。
