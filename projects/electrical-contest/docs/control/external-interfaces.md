# Pi 位姿与 LoRa 协同边界

## Pi 位姿入口

- 车端接收接口：UART4，`PC11` 为 MCU 接收端，115200 8N1。
- 合格输入应是新鲜、已标定、带非零 `CalibrationId` 的 `FIELD_GLOBAL` 位姿；超过 250 ms 视为陈旧。
- 坐标参考点是小车平台中心；不得同时在车端和其他节点重复叠加机械安装偏移。
- 位姿用于标定、显示、任务协调和返程准备，**不进入横向循迹闭环，也不单独触发停车**。

## LoRa 车端职责

- UART5 使用 `PC12` 发送、`PD2` 接收，115200 8N1。
- 新鲜位姿下发送 `CAR_POSE (0x80)`；物理按键请求使用 `CAR_TASK_REQUEST (0x81)`；运行中按键安全停机使用 `MISSION_ABORT (0x84)`。
- 车端只接受与当前任务匹配的状态；ACK、遥测失联或地面站 UI 事件不拥有电机启停权。
- 空中控制器独占相机/MaixCam 会话与飞行决策。车端不生成或解释相机动作序列。

协议细节由项目中的版本化通信规范和当前源代码共同约束。修改帧字段、时隙或任务语义前，应先保留两端带时间戳的原始记录。
