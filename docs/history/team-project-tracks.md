## 时间线维护规则

新增条目必须包含日期、源提交/文件哈希、测试条件、验证等级和证据路径。若一个归档没有 Git 父提交，记录为“快照”，不得为了图谱美观而构造演进关系。

雷达小车的完整调试流水不在本仓库重复维护；当前可执行规则已压缩到 [`../../car/docs/workflow.md`](../../car/docs/workflow.md)，原始版本通过来源仓库的分支与提交记录追溯。
