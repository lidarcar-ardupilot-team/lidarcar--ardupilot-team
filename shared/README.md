# 共用硬件与搭建资料

本目录维护全队共用且可复核的车架、PCB、供电、线束、装配和安全上电事实。它不是任何一个负责人的控制参数仓，也不替代小车、无人机或视觉的模块测试记录。

## 入口

| 需要核对的内容 | 文档 | 当前边界 |
| --- | --- | --- |
| PCB 修订、原理图、Gerber、BOM 与板测 | [pcb/](pcb/) | 已有雷达车原理图 PDF 登记；EDA 源、Gerber、BOM 与板测待补。 |
| 车辆装配、供电和首次上电 | [vehicle-build/](vehicle-build/) | 含安全上电原则和可执行检查单。 |
| 负责人目录与接口交接 | [团队职责与接口](../docs/team-collaboration.md) | 控制、通信和任务行为仍归各模块维护。 |

## 放入本目录的条件

- 该资料被两个或以上模块实际共用；
- 能够说明来源、修订号、适用硬件与核对状态；
- 不包含单个负责人的速度、路径、模型参数、飞控状态机或未验证结论。

PCB、供电或线束一旦改变，先在这里登记版本与板测，再由受影响负责人更新对应的控制/接口文档。首次上电和改线后的最小步骤见 [搭建与上电检查单](vehicle-build/bring-up-checklist.md)。
