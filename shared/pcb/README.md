## 后续导入规则

导入 PCB 文件时新建 `rev-<revision>/`，同时增加：接口表、版本照片、板测记录与变更说明。若引脚或电源网络变化，必须同步更新受影响负责人的控制文档和固件，而不是只更新 PCB 文件。
