# 共用小车搭建

本目录描述团队共用的车辆平台、PCB 管理与安全上电原则；不在此处记录任何负责人的路线、速度、无线状态机或调参结论。

## 平台边界

| 层级 | 共用管理对象 | 记录位置 |
| --- | --- | --- |
| 机械与供电 | 车架、轮组、电池、总地、急停/安全上电 | 本目录 |
| PCB | 版本、原理图、Gerber、接口表、板测结果 | [`../pcb/`](../pcb/) |
| 职责控制 | 传感器角色、引脚、速度和状态机 | 各 `car/`、`aircraft/`、`vision/` 目录 |
| 实车证据 | 测试场地、版本、日志、照片与结论 | 相应负责人目录，不跨职责复用 |

本次迁移已证实的车端参考模块包括：电机驱动与编码器、灰度循迹、姿态输入、串口通信和控制器源码。PCB 原理图、Gerber、线束照片及料号尚未随迁移源提供，必须由团队补充，不能从固件反推。

## 安全上电原则

1. 上电前确认电池极性、保险/开关、驱动器逻辑电源与电机电源，并使所有控制板共地。
2. 首次通电或改线后，使电机驱动 `STBY` 保持安全禁用；先量测供电与逻辑电平，再进行空载轮测。
3. 一轮测试只改变一个变量：线序、方向、PWM、传感器映射或控制参数之一。
4. 记录使用的 PCB 版本、固件提交、测试模式、输入/输出观察和原始证据位置。
