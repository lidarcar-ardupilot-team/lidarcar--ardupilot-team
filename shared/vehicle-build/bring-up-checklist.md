# 小车搭建与上电检查单

> 状态字段：`planned` 未验证；`bench-verified` 台架已验证；`field-verified` 对应赛道已验证。

## 1. 机械与供电

- [ ] 记录车架/PCB 版本、日期和装配负责人。
- [ ] 检查轮组紧固、负载固定、线束应力释放与运动范围。
- [ ] 电机电源、逻辑电源、编码器地和 MCU 地已共地。
- [ ] 在不使能驱动器的条件下量测电压与极性。

## 2. PCB 与执行器

- [ ] 根据 [`../pcb/README.md`](../pcb/README.md) 填入 PCB 版本和原理图/Gerber 来源。
- [ ] 复核每个驱动通道的 PWM、方向和 `STBY`；复核并不等于电机方向已经实测。
- [ ] 抬轮测试：逐轮记录命令符号、实物方向和编码器计数符号。
- [ ] 异常、失联或模式切换时验证驱动输出回到安全状态。

## 3. 传感器与控制入口

- [ ] 先在诊断模式确认灰度/位姿/姿态/通信输入的新鲜度与极性。
- [ ] 将物理位置、输入位、误差符号和控制反应记录在**对应赛事**的控制文档中。
- [ ] 不使用另一赛事的阈值、速度或验收记录替代本赛事实测。

## 4. 证据归档

每次完成后至少保留：固件提交、PCB 版本、测试模式、可复现命令、观测结果和日志/照片路径。没有原始证据时，结论保持 `planned` 或 `reference`。
