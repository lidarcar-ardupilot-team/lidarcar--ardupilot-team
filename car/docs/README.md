# 雷达车 Phase 9 控制快照

## 输入、规划与输出

```text
雷达位姿 + JY901 偏航 + 编码器 + 无线目标
                 ↓
禁区栅格 / A* 规划 / 目标与返航区判定
                 ↓
路径跟随、限速、精停、返航恢复
                 ↓
左右 PWM、电机输出、OLED/串口诊断
```

阶段性的 `empty.c` 具有路线 A/B/C、禁区代价、目标口袋奖励、A* 返航、停靠区、编码器/位姿保护、无线目标与速度闭环相关逻辑。它是当前仓库的**单文件阶段记录**，不定义其他控制器的引脚、通信格式或安全策略。

## 已归档的运行语义

- 规划对禁区使用硬边界、保护距离与软代价；目标附近存在奖励/精停处理。
- 返航使用独立的 A* 速度与转向阈值，并通过返航停车区、倒车恢复和路径守卫限制无效绕圈。
- 无线目标自动启动、位姿新鲜度、编码器上限和航向判定共同参与任务过程；不能以单个雷达点作为全部安全结论。
- `phase9_a_highleft_bx9_bsafe` 的实车验证范围是当时记录的 A/B 空地联调返航停车；其他路线、场地或参数保持 `stage-record`。

## 迁移后的使用要求

1. 先导入对应的 MSPM0 工程和硬件配置，再比较此文件的头文件、引脚及编译选项。
2. 任何再利用均从台架、单路线和单变量测试开始，不沿用其他历史快照的速度/距离阈值。
3. 每次新实车验证应在 `car/` 下追加日期、固件哈希、场地、路线、原始日志和结论。
