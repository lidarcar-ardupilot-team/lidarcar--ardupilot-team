## 程序的实际工作链

```text
STM32F407 飞控
  └─ UART：BB <目标类别> FF
        ↓
MaixCam Pro：读取图像 → find_apriltags() → 选目标中面积最大的标签
  └─ 像素偏差 → 机体系厘米偏差 → 死区 / 限幅 / 一阶低通
        ↓
STM32F407 飞控
  └─ UART：BB <类别> <控制权> <X 符号/高/低> <Y 符号/高/低> FF
        ↓
视觉端：目标居中保持 → PWM 舵机非阻塞开、保持、关
```

代码注释中的“二维码”是任务语义；实现实际使用 `img.find_apriltags()`。因此更换打印物或识别方案时，必须同时更新 Tag ID 映射、飞控目标码、视觉文档和测试记录，不能只改显示文字。

## 维护规则

1. 不提交模型权重、运行日志、原始大视频或设备私有配置；将其放入团队确认的存储位置，并在证据页登记哈希和链接。
2. 不把板载串口帧误写为 [AS32 空地 9 字节帧](../docs/competition/空地联调通信约定.md)。前者服务飞控与相机，后者服务无人机、小车和参赛电脑。
3. 改相机方向、安装高度、坐标轴、Tag 映射、舵机行程或触发条件时，在协议页和同轮测试记录中一起更新；视觉结果不能绕过飞控状态机或小车本地安全判断。
