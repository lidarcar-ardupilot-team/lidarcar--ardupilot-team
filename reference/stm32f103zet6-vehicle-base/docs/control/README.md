# STM32 控制参考

## 控制层级

```text
灰度八通道 → 路径误差 / 丢线判定 → 目标轮速
编码器       → 内环轮速校正          → TB6612 PWM/方向/STBY
JY901 偏航   → 有界航向修正          ↗
Pi 位姿      → 显示、标定与任务协同（不进入横向循迹闭环）
LoRa         → 任务协同与状态通信（不拥有电机启停）
```

该历史基线以灰度循迹为主路径来源；编码器速度反馈与 JY901 偏航修正是辅助层。Pi/雷达位姿和 LoRa 只能提供协调与观测，不能替代灰度路径误差，也不能独立启停小车。
